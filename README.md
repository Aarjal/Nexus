# NEXUS 
#### All in ONE.

## About

Nexus is a custom new - tab page for your web browser with different layouts and functionalities for focus and consistency.

## Features

- A 24-hour live remote running analog clock
- Shortcuts section for your main sites
- To-do list for completion of daily tasks
- Timer of 5 minutes for idk what reason :)

## Installation

1. To clone the repository:
   ```bash
   git clone https://github.com/Aarjal/Nexus.git
   ```
2. To navigate into the project:
   ```bash
   cd Nexus
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
